# Текстуры MDF-рейки — 4 декора

Готовые бесшовные по горизонтали текстуры для стен. Получены из каталожных фото
панели MDF-рейки (2700 × 119 × 16 мм, 3 рейки на панель) и приведены к одному формату.

Превью всех четырёх с двумя повторами по горизонтали: `contact_sheet.png`.
Машинное описание: `manifest.json`.

## Формат

- 1024 × 4096 px, PNG, 8 бит, **RGB без альфа-канала**, sRGB (ICC-профиль не встроен,
  трактуется как sRGB).
- Соотношение сторон 1 : 4 — при квадратных пикселях один повтор = 119 × 476 мм.
- Ориентация: рейки вертикальные, ось **V** идёт вдоль реек.

## Как применять

1. Материал: `Principled BSDF` → **Base Color** = эта текстура.
   Roughness 0.6–0.8, Metallic 0.
   Normal/roughness-карт нет: для реализма достаточно освещения сцены.
2. Повтор (tiling): **только по горизонтали** (U). Стык попадает в канавку между
   рейками, поэтому шов не читается.
3. Масштаб. Чтобы рейка была физически ≈ 39.7 мм, задайте размер одного повтора
   на поверхности:

| Файл | Размер повтора | = реек | ширина рейки |
|---|---|---|---|
| `panel_01_beton_chikago.png` | 143 × 574 мм | 3.6 | 39.7 мм |
| `panel_02_dub_svetly.png` | 131 × 526 мм | 3.3 | 39.7 мм |
| `panel_03_pekan.png` | 190 × 762 мм | 4.8 | 39.7 мм |
| `panel_04_oreh_brazilskiy.png` | 125 × 500 мм | 3.15 | 39.7 мм |

   Если единый масштаб не важен (разные декоры в разных комнатах), можно мапить
   все четыре одинаково — **119 × 476 мм** по паспорту панели. Тогда ширина рейки
   будет разной: ≈ 33 мм (01), ≈ 36 мм (02), ≈ 25 мм (03), ≈ 38 мм (04).
   Для одной стены/комнаты лучше использовать таблицу выше — рейки совпадут по ширине.

4. Вертикальный повтор. Тайл рассчитан на один повтор по высоте; при настиле на всю
   стену (2.7 м ≈ 5–6 повторов) в местах стыков возможна мягкая горизонтальная полоса.
   Практично: прятать стыки за плинтусом/карнизом, планками или мебелью, либо
   разводить повторы по высоте (V-offset) на соседних участках.

## Что учтено при подготовке

- Обрезка выполнена по канавкам, поэтому горизонтальный шов ложится в канавку.
- Выровнены перепады освещения исходных фото (слева-справа и сверху-вниз),
  чтобы на стене не было заметных светлых/тёмных полос с периодом повтора.
- Сшивка по вертикали выполнена плавным кроссфейдом — верх и низ тайла стыкуются.
- Сохранены натуральные особенности: сучки и тёмные прожилки у Пекана,
  крупный контрастный рисунок у Ореха, мелкие поры и неровности у Бетона.
- У Ореха вычищены мелкие белые крапины краски, попавшие на фото.
- Дефекты по краям исходных вырезок (например, диагональный скол у `1.png`) в кадр не попали.

## Ограничения

- Это фотографии каталога, а не сканы: возможны локальные неровности тона и
  лёгкая неравномерность резкости. Для крупных планов (ближе ~30 см) может
  понадобиться доработка.
- Точность масштаба реек ±5 %.
- Прозрачности нет; для «вырезания» реек из фона текстура не подходит — это
  сплошная поверхность стены.
